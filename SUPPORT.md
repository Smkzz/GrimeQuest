# GrimeQuest support

Play at [GrimeQuest on Railway](https://grimequest-web-production.up.railway.app/).
The [README](README.md) describes gameplay and the
[release guide](docs/RELEASING.md) covers building and publishing.

## Common questions

**Do I need an account, product scanner or AI key?** No. Take a before
photo, safely clean the spot, take an after photo and report your own result.
Monsters and XP are fictional game rewards, not hygiene certification.

**The camera does not work.** Check permission on the HTTPS site, or use
the photo picker. If native HEIC/HEIF decoding fails, select/export JPEG.
Do not post real private household photos in an issue.

**The old interface is still displayed.** Finish any active quest, then
choose the in-app **About and settings → Refresh the installed app**.
Installed iPhone PWAs can have storage and caches separate from Safari tabs.

**My points disappeared.** Wins stay in the local browser, not a cloud
account. Clearing data, private browsing or storage restrictions can remove
them. Unfinished photos are intentionally kept only in memory.

**Why no points in the demo?** It uses illustrations, not a real chore,
so awards no XP or creature unlocks.

## Ask for help

Use the [GitHub bug-report form](https://github.com/Smkzz/GrimeQuest/issues/new/choose).
Describe the device/browser, steps to reproduce and expected vs observed
behavior with synthetic or redacted examples. Never include credentials,
addresses or identifying photos.

For vulnerabilities follow [SECURITY.md](SECURITY.md) privately. For
accessibility barriers see [ACCESSIBILITY.md](ACCESSIBILITY.md).
This small open-source project has no guaranteed support SLA.
