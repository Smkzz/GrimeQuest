# Accessibility

GrimeQuest aims to support touch, keyboard, screen reader and reduced-motion
play. It has **not** passed an independent WCAG compliance assessment.

## Included safeguards

- Named buttons and labelled capture/file-picker alternatives.
- Native keyboard-operable before/after range slider with accessible value.
- Text indicating quest stage and collection progress; decorative fictional
  monster illustrations need not be interpreted to play.
- Visible focus indicators, skip-to-main link and reduced-motion support
  that disables character movement and confetti.
- Automated Chromium checks on narrow mobile viewports.

## Work not yet independently qualified

Physical iPhone VoiceOver, Android TalkBack, browser zoom, precise
WCAG contrast compliance, and all possible media-permission prompts still
need manual checks. Unsupported photo codecs may require JPEG export.

## Report an accessibility barrier

Use [the public bug form](https://github.com/Smkzz/GrimeQuest/issues/new/choose)
and choose **Accessibility**. Describe the device, browser, assistive
technology, action, expected result and actual obstacle. Use text or
synthetic examples; do not upload unredacted personal photos.
